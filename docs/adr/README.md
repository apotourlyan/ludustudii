# Architecture Decision Records

Each record captures one decision that is hard to reverse, or that a
reasonable person might make differently: the context, the choice, the
alternatives and the trade-offs. The code shows *what* was decided; these
records explain *why*.

## Rules

- Copy `template.md` to `NNNN-short-title.md`, using the next free number.
  Numbers are never reused or renumbered.
- An Accepted record is not edited, except for its status line and amendment
  notes. To replace a decision, write a new record that supersedes it, and set
  the old record's status to `Superseded by NNNN`.
- To change part of a decision, write a new record that states which rules it
  amends. Once the amendment is Accepted, keep the original record Accepted
  and add an `Amended by NNNN` note linking to the amendment and describing its
  scope. Include that link in the index. The remaining rules stay in force.
- Keep each record to about a page. Anything longer is a design doc.
- Add every record in force to the index below; superseded records are
  listed in [`archive/README.md`](archive/README.md).
- New records start as Proposed. Only the maintainer moves a record to
  Accepted or Rejected; agents may propose but never accept.
- Record decisions, not details. Contract details (limits, formats, status
  codes) belong in the OpenAPI spec and the README; change them there.
- When a topic needs three or more records to understand, consolidate: write
  one record stating the current decision in full, list what it consolidates,
  mark the old ones `Superseded by NNNN`, and move them to `archive/`.
  Numbers are never reused.

## Statuses

| Status | Meaning |
| --- | --- |
| Proposed | Written down but not yet in force. Code doesn't rely on it and nobody has to follow it yet. |
| Accepted | In force. Code follows it; changes require an amending or superseding record. |
| Rejected | Considered and turned down. Kept so the idea isn't proposed again without new arguments. |
| Accepted, Amended by NNNN | A note on an Accepted record linking to a partial change. The record remains Accepted; unaffected rules stay in force. |
| Superseded by NNNN | Replaced by a newer record. Kept as history in `archive/`. |
| Deprecated | No longer applies, and nothing replaced it (for example, the feature it governed was removed). |
